# Website Project
The purpose of this project is to make a basic social media website where user's can share content publically like a social media platform. This is intended to be a professional grade project but not commercial use.

## Features
### Core Features (Required to be considered a "Social Media" platform)
- User Profiles - users must be able to make there own accounts with a unique identity: username and profile page - this is the foundation to any social interaction.
- Content Creation and Posting: The ability for users to share content, whether it's text, images, videos, or links. This is the "media" part of "social media".
- Feed or Timeline: A central place to view content from others.
- Interaction (Likes / Reactions): A basic way for users to achknowledge and react to content. This provides a feedback loop and encourages engagement.

### Baseline Features (Expected and Essentially required but not technically for a "Social Media" platform)
- Following / Friending: A way for users to connect with each other and curate their feed. This is fundamental to building a network.
- Commenting: The ability for users to have a conversation direction on a piece of content. This deepens engagement beyond simple reactions.
- Direct Messaging (DM): Private, one - on - one or group communication. This moves interactions from public to private and is a core part of personal social communication.
- Search Functionality: The ability to find other users, specific content, or hashtags. Without this, the network can feel like a closed ecosystem.
- Notifications: Alerting users to new activity, like comments on their posts, new followers, or DMs. This brings users back to the app.
- Basic Privacy Controls: Allowing users to make their profile private, block or mute other users. This is a crucial safety and security feature.

### Quality-of-Life & Growth Features (Differentiators that Improve User Experience and Drive Growth)
- Hashtags and Trending Topics: A way to organize content and discover what's popular or relevant. This helps with content discoverability and network growth.
- Content Moderation Tools: Automated and manual tools to filter spam, hate speech, and other inappropriate content. This is a critical feature for a healthy and safe community.
- Analytics for Users: Giving users insights into their content's performance (e.g. views, likes, shares). This encourages content creators and helps them grow their audience.
- Live Streaming: The ability to broadcast live video. This is a highly engaging and interactive format that keeps users on the platform longer.
- Stores / Ephemeral Content: Short-lived content that disappears after a certain time. This encourages more frequent, less polished sharing.
- Group Creation / Communities: The ability for users to form smaller, focused communities around shared interests. This fosters deeper connections and niche engagement.
- Content Tagging: The ability to tag other users or locations in posts. This increases engagement and discoverability.
