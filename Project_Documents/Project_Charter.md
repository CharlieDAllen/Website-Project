# Project Scope:
## Business Need:
- This is a social media platform so its purpose would to gain users and thus money = profit for a business
## Project Goals:
- The goal of this project is to produce a simple social media website portpholio piece showcasing my Django, React, PostgreSQL and general programming skills.
## Product Description:
This project is a portpholio piece showcasing my Django, React and PostGreSQL knowledge and my ability to ship a product. The purpose of this project is to ship a fully functioning social media platform that does its core features well first before adding more advanced features.
### What Makes Social Media 'social media':
The core purpose of a social media platform is to share content on the internet and be social, therefore a MVP would simply be:
- Functionality to share content
- Functionality to communicate with others
- Functionality to recieve public content based on some algorithm
Though given time constraints I will add more quality of life features to move it from a bare bones 2000s website to something more user friendly and with more functionality.
## In Scope / Out of Scope
### In Scope:
- The social media platform itself.
- It Works: even if simple, everything that the social media platform IS must function as intended.
- Data Security: all data will still be stored securely.
- Improvements and Optimisations given available time.
### Out of Scope:
As this is a portpholio piece, any sort of real transactions is simply out of scope due to:
- A not having experience processing transactions.
- It being a portpolio piece not made for profit (and it introduces legal liability if it messes up)
- Highly complex quality of life features (project scope just too small)
## Critical Success Factors
- The social media platform works as intended.
## Project Assumptions
- Sufficient knowledge of Django, React and PostgreSQL (lol only ever used SQLite)
- That the technology stack functions as intended and to their respective documentation.
- That this project will take 5 days at 7 - 8 hours of work a day.
## Project Constraints
- Quality - every feature must be properly planned, tested and have fallbacks in event of failure.
- Time - the project has a timelimit of hopefully 5 days. Therefore the most important features must be made first
- Staffing - As this is a portpholio project the only person working on all aspects is me [Charlie](./Contributors/Charlie_Allen.md)
- Computational resources - I'm using my personal PC for this project, and will simulate over network traffic either with my MiniPC or a cheap online cloud server
## Project Deliverables
A functioning social media website.
- Website backend.
- Website frontend.
- SQL database.
- Configured web server to connect it all together.
