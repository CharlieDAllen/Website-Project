# Program Architecture
## Backend
### /accounts:
- User registration / login / logout.
- User profiles and profile customisation.
- Password management.
- User settings (privacy controls).

### /posts:
- Content creation (text + images)
- Feed generation and algorithms.
- Liking / disliking functionality.
- Commenting system.
- Content tagging.

### /messaging:
- Direct message sending / receiving.
- Message threads / conversations.
- Message history.

### /social:
- Following / Unfollowing users.
- Friend requests and management.
- User blocking functionality.
- Notifications system.

## Frontend
### Navigation
- Navigate to profile
- Navigate to feed
- Log out of account

### Accounts
- Add / remove them as a friend
- Add / remove them as a follower
- Message them.
- See public posts.
- See profile information.
